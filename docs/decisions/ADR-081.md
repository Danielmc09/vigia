# ADR-081 · PDF: 20-page cap; WAV: body can't exceed what the header declares (2026-10-28, Claude Code)

**Context.** Deferred "goes with T-10" items from judges T-11 and T-13 before wiring readers to the webhook: a ≤5 MB PDF with thousands of pages was billed whole; a WAV with a faked `nframes` passed `check_wav` declaring few seconds while sending the full file (up to ~5 min billed).

**Decision.** `check_pdf` takes the larger of the page-tree `/Count` and the raw-byte count of `/Type /Page` and rejects > `PDF_MAX_PAGES = 20` (`TOO_LARGE`); `check_wav` rejects if `len(data)` exceeds header + frames×2 + margin (`UNSUPPORTED_AUDIO`). Incident tests written first.

**Why.** An invoice or statement forwarded for verification has few pages.

**What would invalidate it.** Real legitimate PDFs over 20 pages, or pages hidden in compressed object streams the counter misses.
