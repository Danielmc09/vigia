# ADR-034 · Fusion without an analyst: hard -> scam 0.9; two distinct medium types -> scam 0.8; never legitimate (2026-10-27, Claude Code)

**Context.** specs/05 defines fusion with an analyst; `--rules-only` and degraded mode must decide on signals alone.
**Options.** Count medium signals (two URLs with an odd TLD = two mediums); count distinct types; allow "legitimate" if all URLs are official.
**Decision.** Distinct types (`MEDIUMS_FOR_SCAM = 2`), and never legitimate without an analyst.
**Why.** The same clue repeated isn't independent evidence; an official domain doesn't prove the message is legitimate (the contact number or text could be the scam), and a wrong "legitimate" is the expensive error. Cost: legitimate messages come out doubtful in this mode (accuracy is low here, doubtful ~0.6), which the analyst resolves.
**What would invalidate it.** The analyst missing for the demo → a rule "only official links and no patterns -> legitimate 0.7" with its own eval.
