# ADR-012 · Owner queries gated by "numbers in the text ⊆ the data" (2026-10-27, Angel)

**Context.** The owner wants to ask questions over WhatsApp; rule 14 forbids free model text to the user.
**Options.** Don't offer it; fixed templates with no model; model with read tools plus deterministic verification of the answer.
**Decision.** The third, owner only, with `business_id` fixed by code and a daily cap.
**Why.** Keeps the guarantee that the model can't invent figures (it's verified) and keeps the surface small (reads, no free SQL).
**What would invalidate it.** The gate discarding > 20% of answers (then use templates).
