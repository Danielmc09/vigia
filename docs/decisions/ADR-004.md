# ADR-004 · Redis only in layer 2 (2026-10-27, Angel)

**Context.** Scaling analysts across replicas.
**Options.** Queue from the start; in-process analyst first.
**Decision.** In-process in layer 1, Redis in layer 2 behind the same `analyze()` function.
**Why.** The layer-1 video doesn't need a queue; the interface doesn't change.
**What would invalidate it.** Nothing; it's sequencing, not architecture.
