# ADR-094 · The impersonated brand is also read from the message body, only once it's already a scam (2026-10-30, Claude Code)

**Context.** Incident c-0211/c-0212 (real Coordinadora scam, Oct 30): a raw-IP link convicted the case, but the verdict and team alert came out with no brand named. The brand was only ever detected in the link's host or path. The capital "I" in "CoordInadora" wasn't the cause: lowercased, the name is identical.

**Options.** (a) a new `signals/brand_in_text` signal — would move fusion, and a brand name in text alone proves nothing (legitimate messages name brands too). (b) in `build_verdict`, if the label is already scam and no hard signal carries a brand, look for a pack brand's name as a whole word in the body; names only, never changes the label or confidence.

**Decision.** (b). `_brand_in_body` in `verdict/build.py`. Case-insensitive, but an all-lowercase occurrence doesn't count ("claro", "dale", "envía" are common words). The brand name comes from the pack, never echoed from the text (rule 14).
