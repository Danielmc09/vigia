# ADR-008 · Panel login via a WhatsApp link, no password (2026-10-27, Angel)

**Context.** The owner needs to see their business without letting an employee in; no time for web auth.
**Options.** Username/password; SMS OTP; one-time token link via WhatsApp.
**Decision.** `panel` → single-use 15-minute link → 24-hour session; owner role only.
**Why.** WhatsApp is already the verified identity; zero passwords to steal; two OWASP tests cover it.
**What would invalidate it.** Wazenda not allowing links to be sent (it does).
