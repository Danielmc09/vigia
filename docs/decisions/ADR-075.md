# ADR-075 · The blind evaluator runs on a different model (2026-10-27, Claude Code)

**Context.** specs/06 requires "a model different from the one that wrote the code"; `evaluador-ciego` had no fixed `model:` and ciego-01 ran on the orchestrator's own model.

**Decision.** `model: sonnet` in `.claude/agents/evaluador-ciego.md` from ciego-02 onward; ciego-01 is recorded as the same model and is not cited as "a different model" in the video.

**What would invalidate it.** Access to a different provider's model for the evaluator (even better).
