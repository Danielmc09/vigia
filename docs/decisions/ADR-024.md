# ADR-024 · Test/build tools: anyio, uv_build, httpx tolerated (2026-10-27, Claude Code)

**Context.** Async tests against Postgres and packaging the project with uv.
**Options.** pytest-asyncio or the pytest plugin already bundled with anyio (a FastAPI dependency); hatchling or `uv_build`; migrate now to `httpx2` or tolerate the warning.
**Decision.** The anyio plugin (`pytest.mark.anyio`), `uv_build` backend, and tolerate `StarletteDeprecationWarning` from `httpx` in `TestClient`.
**Why.** anyio and uv_build add no dependencies; migrating to `httpx2` was denied for permission reasons and is Angel's call.
**What would invalidate it.** The warning becoming an error in a future Starlette version, or Angel approving `httpx2`.
