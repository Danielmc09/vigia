# ADR-013 · Observability with free tools plus a sentinel, no owned stack (2026-10-27, Angel)

**Context.** Knowing about a failure before the business does.
**Options.** Prometheus+Grafana+Loki in compose; Railway logs + /metrics + Sentry + sentinel + WhatsApp alerts.
**Decision.** The second. **Superseded by D-112:** no hosted instance; the sentinel/Railway logs path is moot without a deployment.
**Why.** The sentinel (3 canonical cases every 15 min) catches what matters (renamed model, changed format, slowness) and every alert carries a runbook; an owned stack eats day 5.
**What would invalidate it.** Railway not retaining enough logs → Grafana Cloud free tier.
