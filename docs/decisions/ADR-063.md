# ADR-063 · `analyze_url` returns `unknown_domain` (light) when no rule fires (2026-10-27, Claude Code)

**Context.** `signals/urls.py:url_signals` returns `[]` for a domain that matches no brand and has no risk traits (e.g. `x.example`); the model read an empty list as "clean".

**Decision.** Only in the tool output (`services/analyst_tools.py:_analyze_url`), add `Signal(type="unknown_domain", weight="light", source="urls")` and `official: false`. It never enters `Evidence` and never moves fusion.

**Why.** The prompt tells the model never to assume a domain is official; the tool has to say so with data.

**What would invalidate it.** `url_signals` emitting that signal on its own (then this addition is removed).
