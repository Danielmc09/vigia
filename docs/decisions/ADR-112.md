# ADR-112 · Railway discarded: there is no hosted instance; the judge's path is `make demo` (2026-10-31, Angel)

**Context.** T-19 called for deploying on Railway (Postgres + api + analyst, with Wazenda's webhook pointing there). On Oct 30, from the Railway container, `GET /v1/models` returned `200 []` and `POST /v1/chat/completions` → 404 `model_not_found`: a Meta entitlements bug prevents calling the model from there, and the app degraded everything to rules. Cerebral Valley officially responded that judges don't need a hosted version.

**Options.** (a) keep fighting region/entitlements on Railway. (b) fall back to another chat backend from Railway (T-19d). (c) discard hosting: the judge runs `make demo` (Docker Compose + Dockerfile) on their own machine.

**Decision.** (c). T-19 and T-19b are discarded (the weekly feeder needed a host to run it; new entries are proposed by Claude Code by hand and approved by Angel). The `Dockerfile`, `docker-compose`, and `make demo` stay: they are the judge's path. The README points to no hosted URL.

**Why.** (a) depends on a Meta bug outside our control, 4 days from the deadline; a URL that degrades to rules in front of the judges is worse than no URL at all. (c) costs nothing and is what CV asked for.

**Inherited condition.** D-111: `/caso` is public and tokenless, acceptable only because there is no reachable instance. If it is ever deployed, `/caso` goes behind a token like the panel before the port is opened.
