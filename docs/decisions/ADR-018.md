# ADR-018 · Shared code grouped by cohesion, never a `utils.py` (2026-10-27, Angel)

**Context.** Temptation to have one file with "everything used more than once".
**Options.** `utils.py`; group by owning concept with a rule-of-three.
**Decision.** Group by concept; `utils/helpers/common` forbidden; `make dup` as detector.
**Why.** `utils.py` grows without an owner and breaks the dependency direction; cohesion keeps the repo map readable.
**What would invalidate it.** Nothing.
