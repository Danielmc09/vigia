# ADR-067 · `amounts`: only counts as money what carries `$`, a thousands separator, or a scale word (2026-10-27, Claude Code)

**Context.** `price_below_market` and `staggered_charges` need amounts; a bare number ("NMax 2023", "256 GB", a masked phone) is not money.

**Decision.** `domain/text.py:amounts` reads over `fold(text)` numbers with `$`, thousands separators (`\d{1,3}([.,]\d{3})+`, dot in CO, comma in US), or a scale word (`mil`, `millón/millones`, `k`). Returns floats in text order.

**Why.** Most messages carry no currency symbol and the decimal convention changes by country; these three markers produced no false positive across the 13 `compraventa` cases.

**What would invalidate it.** Unmarked prices ("at 900") the set needs to read.
