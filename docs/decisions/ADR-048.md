# ADR-048 · `POST /case`: public, unauthenticated endpoint, `origin="eval"`, a random business per request (2026-10-27, Claude Code)

**Context.** T-07's "done when" needs `POST /case` to return a valid `Verdict` with a mocked analyst, before the webhook (T-10), the per-business API key (T-17b) and the real analyst (T-09) exist.
**Options.** (a) require an API key already, inventing a table T-17b will design; (b) tie the request to an enrolled business, forcing Postgres and the vault open just to classify text; (c) a stateless endpoint: build an `IncomingMessage` (`origin="local"`), run it through the same `normalize` the real channel uses, mark the `Case` with `origin="eval"` and `sender=None`, a random non-existent `business_id`, run `detect` + `build_verdict`, persist nothing.
**Decision.** (c), in `src/vigia/app.py`.
**Why.** It reads and writes no business data (no PII to leak, no RLS to bypass); the analyst is injected (`create_app(config, analyst=...)`, `None` by default -> a degraded verdict), so neither tests nor this endpoint call a model unless asked; `origin="eval"` guarantees policy never executes an irreversible action from here. It shares `signals/knowledge.py:seeded_pack` with `measure.py` so the endpoint and the grader never diverge.
**What would invalidate it.** The endpoint getting wired to the real analyst (spends credits on anonymous requests -> needs an API key and a cap, T-17b), or starting to persist cases (needs a real business and RLS) — either moves it out of "public".
