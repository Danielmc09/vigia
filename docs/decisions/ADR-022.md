# ADR-022 · asyncpg directly; SQLAlchemy deferred until T-04 (2026-10-27, Claude Code)

**Context.** specs/00 lists SQLAlchemy + asyncpg; T-00 only applies migrations and sets `app.business_id`.
**Options.** SQLAlchemy from the start; asyncpg directly.
**Decision.** asyncpg directly (the runner needs asyncpg's simple protocol to execute multi-statement files anyway). `DATABASE_URL` moves to `postgresql://` (was `postgresql+asyncpg://`).
**Why.** No line of T-00 benefits from the ORM.
**What would invalidate it.** T-04 introducing `Encrypted`/`Hashed` as SQLAlchemy `TypeDecorator`s (specs/16 §3) → SQLAlchemy enters there and `set_business` adapts.
