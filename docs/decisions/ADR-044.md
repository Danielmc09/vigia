# ADR-044 · Quoting a known domain to deny it, not to invite it: fusion softens only on a negation whose object is that domain (2026-10-27, Claude Code; revised twice after judge T-07)

**Context.** Incident c-0076: "Team, heads up: DIAN warned that diangov.com is a fake site, do NOT go there" triggered hard `known_campaign` and scored scam 0.9, even though the message denies the domain. `extract_urls` has no sentence-level notion (D-039).
**Options.** (a) fix it in `policy/` (decides actions, not labels); (b) treat any alert word ("careful", "warning") anywhere in the text as a softener; (c) require an explicit negation of the quoted domain.
**Decision.** (c), in `verdict/fusion.py:soften_citations`. The pack gets a `negation` pattern category (explicit denials only: "is fake", "is a scam", "don't click/open/enter/pay"). A `known_campaign` match drops to `light` only if it matched by domain and a negation appears in the SAME sentence as that domain; a text- or image-fingerprint match never softens.
First judge pass (incidents c-0077..c-0079) found this let real scams through when the scam itself opens with an alert word ("ALERTA DIAN: ... pay today at diangov.com"); the "same sentence" rule alone wasn't enough.
**Second revision** (incidents c-0080..c-0082): "same sentence" still softened scams where the negation denied something else ("don't panic, ... today at diangov.com"). The negation must now take the domain as its grammatical object within the same clause: a negation verb immediately before it (joined only by fixed connectors) or a negation predicate opening right after the domain ("diangov.com is a fake site"). "diangov.com is not fake" no longer softens (the predicate must open the clause).
**Why.** Catches the real "this domain is fake, don't fall for it" pattern while refusing to be fooled by scams that merely open with a warning word.
**What would invalidate it.** A legitimate warning with the negation far from the domain still condemning the message → incident + more connectors, or leave it to the analyst (T-09).
