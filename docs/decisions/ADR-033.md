# ADR-033 · No QR decoder until T-12 (2026-10-27, Claude Code)

**Context.** specs/04 asks for QR decoding; `pyzbar`, `zxing-cpp`, `opencv` and `Pillow` aren't installed and no dependency is added in T-06.
**Options.** Add `zxing-cpp` now; keep the interface with an injectable decoder that returns `[]` for now.
**Decision.** `decode_qr` returns `[]`; `qr_signals(image, pack, decode=...)` takes the decoder and applies the same URL rules with `origin="qr"` plus `qr_to_unofficial_domain`; a `xfail(strict=True)` test marks what's missing.
**Why.** No text case has a QR; T-06's recall doesn't change and T-12 (screenshots via SAM) picks the library using real images.
**What would invalidate it.** T-12 starting → the dependency is added and the xfail turns green (strict forces it). **Resolved by D-076** (T-12: zxing-cpp + Pillow).
