# ADR-102 · Redirect evals run on a fixture, never real network (2026-10-31, Claude Code)

**Context.** `measure.py` must be deterministic, and shortener cases can't depend on the link staying alive.

**Decision.** `evals/redirecciones.json` maps URL → `Location`. `measure.py` runs the real unroller with a fake transport (redirects if the URL is in the map, 200 otherwise) and a fake DNS (hostnames resolve to a public IP, literals to themselves), so the 169.254.169.254 guard actually runs. URLs outside the map don't redirect: same signals as before.

**What would invalidate it.** A case needing to model timeouts or a 405 HEAD; covered today by unit tests.
