# ADR-046 · `DEFAULT_REPORT_TARGET` is a documented placeholder until Angel provides the real contact (2026-10-27, Claude Code)

**Context.** `policy/actions.py:new_escalation("report", target, business_id, now)` needs a destination while T-09/T-10 don't yet know who to report to (no CSIRT or real inbox defined).
**Options.** Leave `target` without a default, forcing every caller to invent one; a documented placeholder constant.
**Decision.** The second: `DEFAULT_REPORT_TARGET = "csirt@vigia.local"` (a reserved, non-resolving domain).
**Why.** An explicitly named placeholder is easier to `grep` for before the demo than a silent optional parameter someone forgets to pass.
**What would invalidate it.** The real report channel needing more than one string (e.g. an authenticated webhook) → move it to `Settings` instead of a module constant.
