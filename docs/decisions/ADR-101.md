# ADR-101 · The analyst's `analyze_url` uses the pre-resolved map; the model never issues network requests (2026-10-31, Claude Code)

**Context.** Exposing `resolve_url_redirects` as a model tool would hand it an outbound-request primitive with a model-chosen URL, which can come injected from the message.

**Options.** (a) a network tool for the model. (b) `analyze_url` receives the case's map as a closure.

**Decision.** (b). `Evidence.links` carries the map built by code; `spark_analyst` binds `analyze_url` to that map. The model sees the resolved destination of links in the case; one not in the map is never followed.

**What would invalidate it.** Cases where the link to investigate isn't in the case text (doesn't apply today).
