# ADR-071 · Spark reads the PDF in code before signals, no PDF library (2026-10-27, Claude Code)

**Context.** T-13 needs PDFs.

**Options.** (a) a PDF library (pypdf/pdfminer); (b) Spark chat with the PDF as a `file` (verified in T-02); (c) render page 1 to an image.

**Decision.** (b), mirroring D-070. `domain/attachment.py:check_pdf` (size cap first → `TOO_LARGE`; then `%PDF-` magic → `INVALID_ATTACHMENT`); `model/spark.py:SparkClient.read_pdf(pdf, language)` sends `{"type":"file","file":{"filename","file_data":"data:application/pdf;base64,..."}}` with strict `json_schema` `PdfText {text: string}` and a prompt asking for a literal transcript, treating the document as data, not instructions; it satisfies `domain/voice.py`'s `Transcriber` port (`audio_ms` defaults to 0). `ModelRequest` gains `output_name` and `max_tokens`. `services/transcription.read_pdf` checks before spending; `reply(rejection, lang, PDF_REPLY_KEY)` → `pdf.invalid/too_large/unavailable`. The text goes to `Case.text`, `kind` stays `pdf`, feeds only signals and the analyst, never shown to the user (rule 14). Caps: `Settings.pdf_max_bytes` (`VIGIA_PDF_MAX_BYTES`, 5 MB), output 3000 tokens (`PDF_MAX_TOKENS`), timeout 30 s. HTTP/shape/JSON failure = retryable `MODEL_UNAVAILABLE`. `tools/measure.py`: per-type readers, cost logged as tool `read_pdf`; `--solo-deterministas` and no key both skip PDFs (`NO_PDF`), like audio.

**Why.** Installing dependencies is denied and a library can't read scanned PDFs; option (c) loses the exact text of links.

**Known ceiling.** The number of pages is not bounded within the 5 MB cap (only the output is).

**What would invalidate it.** Accuracy for `tipo=pdf` < 0.80 with the real analyst, or Spark rewriting links (read domain ≠ PDF's domain).

**Revision** (reviewer T-13): `PDF_PROMPT` stays a constant in `model/spark.py`, not in `analyst/prompts/`: the import-linter contract forbids `model` importing `analyst`, and it is a 3-line instruction for an attachment reader (not the agent's prompt); moves to a file if it grows or the analyst reuses it.
