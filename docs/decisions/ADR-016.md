# ADR-016 · Documentation generated and verified, never hand-written and abandoned (2026-10-27, Angel)

**Context.** "Where everything lives and what it does" goes stale within a week if manual.
**Options.** A manual wiki; docstrings + a generated map + pdoc + CI diff.
**Decision.** The second, with `interrogate >= 90` and a regenerated `MAP.md` inside `make check`.
**Why.** Docs that fail the build when they lie are the only ones that survive a hackathon.
**What would invalidate it.** Nothing.
