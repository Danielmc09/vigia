# ADR-086 · Spark's content filter = degraded mode; Muse Spark Open on Baseten as a chat backend (2026-10-28, Claude Code)

**Context.** T-09b. Discord #meta (poll, Oct 28): `muse-spark-1.3` answers `400 content_policy_violation` to legitimate security text. VIGÍA processes scams all day; if that 400 becomes an error or silence, the member gets no reply. Muse Spark Open on Baseten has no such filter and earns the Open Weights bonus.

**Options.** (a) treat the 400 as `MODEL_UNAVAILABLE` (what the code did): the analyst returns `None`, but a filtered PDF/screenshot answers "couldn't read it" with no verdict at all. (b) new code `CONTENT_FILTER`: the analyst and readers degrade to a deterministic verdict with light signal `model_could_not_verify` (i18n es/en); the judge falls to `MOCK_ANSWER` (triage `investigate`) with no signal. (c) auto-retry on Baseten when Meta filters — discarded for now: mixes backends in one case and doubles cost; revisit if the filter shows up in real evals.

**Decision.** (b) + a `MODEL_BACKEND=spark_open` backend chosen by configuration.
- `model/spark.py`: `Endpoint(base, models)` with `META` and `SPARK_OPEN` (`https://inference.baseten.co/v1`, `meta-models/muse-spark-open-1026`, falling back to `meta-models/muse-spark-open` on `404 model_not_found`). `SparkClient` takes the `Endpoint`; no new class.
- `services/backend.py:make_chat` picks the backend (specs/09 §19: one adapter never imports another). Used by the judge, the webhook's analyst, and `measure.full`.
- `spark_open` only covers chat (analyst and judge). PDF/image readers, SAM, Voice, and `web_search` stay on Meta; Baseten only serves chat completions. With `spark_open`, the analyst's `web_search` falls back as a rejection-as-data.
- Pricing: baseten.co/pricing (Oct 28) gives $1.25/$0.15/$4.25 per million (input/cache/output), same as Spark 1.3: `usage_usd` serves both.
- Signal with `source="analyst"`, light weight: informs the explanation, never decides (rule 5).

**What would invalidate it.** If real evals show Meta's filter rejecting more than 5% of cases, switch to (c) or default to `spark_open`; if Baseten's pricing or error shape differs, adjust `Endpoint`/prices with a verified fixture.
