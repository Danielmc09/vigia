# ADR-056 · `--rules-only` runs through the gate floor, and a flagged legitimate case fails the run (2026-10-27, Claude Code)

**Context.** Judge T-08: `manipulation` patterns (D-051) false-positived on ordinary legitimate text ("You are now enrolled in paperless billing"), and nothing measured it: `tools/measure.py:deterministic` never called `screen`, and even if it had, without an analyst the code can never say `legit` (specs/05 rule 4), so the flag moved no label in that mode.
**Options.** (a) only measure in full mode (needs credits, doesn't run today); (b) an informational metric with no threshold (nobody looks at it); (c) a hard ceiling metric even in rules-only mode.
**Decision.** (c). `deterministic` now calls `screen(...)` and records `manipulation` per case; new metric `manipulacion_legitimo` (flagged legitimates / legitimates) with a hard `FLOOR_MAX` of 0.0, checked in both modes.
**Why.** The floor is deterministic; D-051 already treats every false positive there as an incident, so the ceiling is 0, not a tolerance.
**What would invalidate it.** Once the analyst (T-09) is in place and there are enough legitimate cases to measure the flag per-label in full mode, the ceiling could become an alert instead of a hard gate.
