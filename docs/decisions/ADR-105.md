# ADR-105 · WhatsApp, Meta, Facebook, and Instagram in the country packs as user-generated-content domains (2026-10-31, Claude Code)

**Context.** Angel asked for all four brands in CO and US with verified sources (meta.com/gb/account-recovery-support; facebook.com/help/1634546593478660; faq.whatsapp.com/854037192262196; faq.whatsapp.com/506595211487528 — never share the 6-digit code). Listing instagram.com as official made a probe ("catalog at instagram.com/<profile>, send us your password") drop from scam to doubtful: the official link disarmed `credentials_request`. Anyone can publish on these hosts.

**Options.** (a) don't list facebook.com/instagram.com — then the host itself fires a hard `brand_off_domain` on every legitimate link to Facebook. (b) list them as official — regression of the probe above. (c) a per-brand `contenido_de_usuarios` field: these domains are neither official nor off-domain (no signal), still feed lookalikes, and don't count as official for credentials or the legit guard.

**Decision.** (c). User-content domains: whatsapp.com (chat.whatsapp.com), facebook.com, fb.com, instagram.com. Pure official: meta.com, metamail.com, facebookmail.com. wa.me is not listed (link to any number). Meta is `ambigua` ("meta" = goal/target). `tipo: plataforma`. The link-less 6-digit-code scam (c-0222, c-0223) falls under rule 3: urgency alone is medium, the analyst breaks the tie; without an analyst it comes out doubtful.

**What would invalidate it.** A legit message linking an official Meta page on facebook.com coming out doubtful because of it, or degraded mode letting the code theft through in evals (then a rule: asking for a code + naming the platform = medium).

**Addendum (reviewer/judge, incidents c-0224..c-0226).** (1) Domains were drawn from the email-sender allowlist, not from link hosts: fb.me (Facebook's own shortener) and meta.ai gave hard lookalike + off-domain signals. Both are now listed; fb.me also as user content. (2) An ambiguous brand in the host weighs at three levels: hard if in the registered domain (meta-soporte.xyz) or if the host spells out the full official domain (chase.com.secure-login.ru, c-0055), with label boundaries (purchase.com is not Chase); medium if it's only a foreign subdomain (claro.pagos-online.co, meta.wikimedia.org), the most common phishing shape and also a common word; path doesn't count (/meta/ofertas). (3) `knowledge.py:_linked` also ignores user-content domains: an instagram.com profile is not a campaign fingerprint. (4) Reviewed every consumer of `official_domains()`: urls.py, knowledge.py, verdict/build.py (legit guard; user-content domains deliberately don't satisfy it). `analyst_tools.py` uses `aliases()`, unchanged. Open gap: whatsapp.net (media CDN) stays off-domain; added if it shows up in evals.
