# ADR-062 · `make evals-rapido` = the 66 `rapido:true` cases (not 30), $1 cap; `make evals` $2 cap (2026-10-27, Claude Code)

**Context.** specs/06 says 30 fixed `rapido:true` cases; the set has 66 marked (all text, 32 scams and 34 legit).

**Options.** unmark 36 by hand to cut cost, or run all 66.

**Decision.** All 66. The first run cost $0.123 and 64 s: well under the $1 cap (rule 11), and more cases give a less noisy figure. `Makefile`: `evals` = `measure.py --max-usd 2.0`, `evals-rapido` = `--filtro rapido=True --max-usd 1.0`, both via `uv run --env-file .env` (the key enters the process without being read as text). With `--filtro` the specs/06 gate (recall ≥0.90, fp ≤0.10, doubtful ≤0.25) still applies, but regression is not checked nor is the baseline written (D-029).

**Why.** Richer signal for the same low cost, no change to the gate.

**What would invalidate it.** Per-case cost rising (images, audio from T-11/T-12) pushing the fast run past ~$0.5; then it gets trimmed to a fixed 30.
