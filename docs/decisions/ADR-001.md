# ADR-001 · Postgres from day one (2026-10-27, Angel)

**Context.** Multi-business isolation is required; layer 2 runs several containers.
**Options.** SQLite now, migrate later; Postgres from the start.
**Decision.** Postgres with RLS from T-00.
**Why.** Migrating from SQLite mid-hackathon costs more than starting with compose+Postgres; RLS gives isolation even if the code has bugs.
**What would invalidate it.** Railway not offering Postgres (it does).
