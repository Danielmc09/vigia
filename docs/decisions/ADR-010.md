# ADR-010 · OWASP Web Top 10 as tests, not a checklist (2026-10-27, Angel)

**Context.** The API and panel expose business data.
**Options.** Manual audit at the end; per-category tests from T-00.
**Decision.** `make security` (bandit, pip-audit, test_owasp, test_security) inside `make check`.
**Why.** A rule that doesn't run in CI doesn't exist under deadline pressure; it adds evidence to the 20% technical score.
**What would invalidate it.** Nothing.
