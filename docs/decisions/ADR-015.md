# ADR-015 · Code, commits and public docs in English; UX in the business's language; specs in Spanish (2026-10-27, Angel)

**Context.** Judges and partners are in the US; users are in LATAM; Angel works in Spanish.
**Options.** Everything in Spanish; everything in English; split by audience.
**Decision.** Split by audience (specs/13 §1) with `i18n/` for user-facing text and a test that forbids literals outside it.
**Why.** A Spanish-only repo gets dismissed in 30s abroad; English-only UX gets dismissed in 30s in a corner store; specs are Angel's own notebook.
**What would invalidate it.** Nothing.
