# ADR-019 · Full conversations as a case, with sequence signals (2026-10-27, Angel)

**Context.** The marketplace scam (puppy, car, rental) is not one message but a curve: deposit → new charges → pressure; message by message it looks normal.
**Options.** Ignore it; ask the user to forward "the bad message"; accept the exported chat and analyze the sequence.
**Decision.** The third, with deterministic sequence signals (two hard ones) and a different reply if the victim already paid.
**Why.** It's one of the scams that drains the most money from people and businesses, anyone in the room recognizes it, and exported chats are a native WhatsApp feature.
**What would invalidate it.** The export parser failing on > 10% of real formats → ask for screenshots instead.
