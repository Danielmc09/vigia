# ADR-029 · `measure.py`: injectable classifier, gate only in full mode, `latest` only from clean runs (2026-10-27, Claude Code)

**Context.** T-05 requires `measure.py` before signals (T-06), `/case` (T-07) and `evals/adversarial.jsonl` (T-08) exist; specs/06 defines a gate (recall >= 0.90, fp <= 0.10, doubtful <= 0.25, no metric drops > 2 points vs `latest.result.json`).
**Options.** (a) wait for T-07 to write the runner; (b) a runner with the system under test as an injectable `Case -> Outcome` function, deterministic path by default; (c) for `--adversarial` with no file, run empty and exit 0 vs. fail with a clear message.
**Decision.** (b). `tools/measure.py` takes a `Classifier`; `--rules-only` uses `deterministic()`, which without signals returns a degraded `doubtful` (specs/05 rule 4) and is the only line T-06 changes; full mode and `--adversarial` exit with code 3 and a clear message until T-07/T-08 exist (running empty would give a green result over nothing). `--rules-only` skips the threshold gate (it measures "how much the code alone solves", T-06 targets 0.60, not 0.90) but does check regression against its own `latest.rules-only.result.json` baseline. `latest*.result.json` updates only on an exit-0 run without `--filter`: if a regressing run became the baseline, regression would vanish within two runs. A run stops as soon as spend passes `--max-usd` (exit 2), not at the end. The 60s timeout is enforced by the caller (T-07, the HTTP client); the runner treats `TimeoutError` as a failed case and continues. `hypothesis_confirmed` means the predicted label matched (the hypothesis is free text; matching it against signal names comes with T-06).
**Why.** Tests exercise the grader against a fake app with no network, and T-06/T-07 plug in without touching the grader.
**What would invalidate it.** `/case` (T-07) returning something that doesn't fit `Outcome` → `Outcome` gets replaced by the domain `Verdict`.
