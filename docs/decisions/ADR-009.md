# ADR-009 · Knowledge base kept separate from evals, with checked hygiene (2026-10-27, Angel)

**Context.** VIGIA should recognize already-reported campaigns without spending on the model.
**Options.** Put campaigns in the prompt; a deterministic signal with fingerprints.
**Decision.** `known_campaigns` table with simhash/pHash/domains → a hard signal; `validate_cases.py` forbids an eval colliding with the base.
**Why.** Deterministic, cheap, and keeps evals from measuring memory instead of capability.
**What would invalidate it.** A fingerprint-collision false-positive rate > 1% → raise thresholds.
