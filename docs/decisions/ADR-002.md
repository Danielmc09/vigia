# ADR-002 · Spark as a tool-using agent, not a single call (2026-10-27, Angel)

**Context.** 25% of the score is creative use of Meta models; Spark is tuned for tool loops.
**Options.** One multimodal call with JSON; a loop with tools.
**Decision.** A loop with 9 scoped tools, cap of 6 steps/25 s, schema-validated output.
**Why.** The model decides *what to look at* (SAM, Voice, the supplier book) and the code decides *what happens*; this shows in the panel and the video.
**What would invalidate it.** T-02 showing `tools` doesn't work on the Model API → fall back to a single call with fixed pre-extraction.
