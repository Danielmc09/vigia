# ADR-014 · The front end has nothing to protect (2026-10-27, Angel)

**Context.** Lesson from a prior 30-hour hackathon: obfuscation makes things harder, not safe.
**Options.** SPA with logic and obfuscation; server-rendered panel with minimal JS and CSP.
**Decision.** The second, with a test that greps the bundle for forbidden terms.
**Why.** A scammer must not be able to read the patterns or thresholds; every role decision lives in the backend (A01).
**What would invalidate it.** Nothing.
