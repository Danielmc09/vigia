# ADR-003 · Own loop before Hermes (2026-10-27, Angel)

**Context.** Hermes has a `meta-ai` provider and MCP, but it's a new dependency with per-process latency.
**Options.** Hermes from day one; own loop, Hermes in layer 3.
**Decision.** Own loop (~150 lines) with the same `Analyst` interface; Hermes only if layer 2 is green.
**Why.** Guaranteed structured output and evals without an external process; Hermes helps more in local Glimmer mode.
**What would invalidate it.** The own loop having worse recall than Hermes in evals-rapido.
