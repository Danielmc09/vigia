# ADR-006 · Deterministic rules override the model (2026-10-27, Angel)

**Context.** Scamio and peers fail by not giving firm verdicts.
**Options.** The model decides with rules as context; hard rules override it.
**Decision.** Hard rules → always scam; two medium rules → scam; the model only explains or resolves what has no hard evidence.
**Why.** Reproducible, testable without an LLM, and the approach that won the Caja Negra hackathon.
**What would invalidate it.** `fp_legitimo` > 0.10 from overly aggressive rules → lower weights, don't drop the rule.
