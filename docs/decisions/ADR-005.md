# ADR-005 · The model judge is auxiliary, never a decision-maker (2026-10-27, Angel)

**Context.** Filtering the obvious and detecting manipulation cheaply.
**Options.** The judge decides verdicts; the judge is only a gate.
**Decision.** Gate with chat context and a mock fallback; it never changes a verdict by itself.
**Why.** Independent evaluators show that mapping "answer → action" with the model is a source of errors; policy is code.
**What would invalidate it.** Nothing during the hackathon.
