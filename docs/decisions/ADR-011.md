# ADR-011 · Per-business API key before a remote MCP (2026-10-27, Angel)

**Context.** Businesses that want their own dashboard or to connect an assistant.
**Options.** MCP first; REST API first.
**Decision.** `/api/v1` with `apikey` in layer 2; read-only remote MCP in layer 3.
**Why.** The API is 10 endpoints over what already exists and the panel uses it; the MCP is a separate story for the video, and the hackathon rewards one.
**What would invalidate it.** Official Rules rewarding assistant integrations.
