# ADR-089 · "Try it" is a form that POSTs to `/panel`, text only (2026-10-30, Claude Code)

**Context.** T-22d asks the panel for a text field, a file picker, three one-click examples, and the verdict on screen, with no client-side logic. The panel has `default-src 'none'` CSP, no scripts (D-073), and `/caso` only takes JSON, no attachments.

**Options.** (a) JS `fetch` to `/caso` — breaks the no-script CSP. (b) multipart with attachments — `/caso` doesn't accept them yet and duplicates the channel's ingestion. (c) a server-rendered `<form method="post" action="/panel">` with examples as `name="text"` buttons; the verdict goes through `judge_text`, the same closure `/caso` uses; `VerdictRow.of` lives in the domain, shared by the store and the panel.

**Decision.** (c). No JS needed, CSP unchanged, the route requires the same token/cookie as the panel. The `SameSite=Lax` cookie doesn't travel on a cross-site POST. Country fixed to CO (`TRY_COUNTRY`). No file picker, no QR screenshot example. Uses `/caso`'s analyst, which is `None` in the public app, so the verdict comes out degraded and the legit example shows "doubtful". Example texts live in `i18n/` (keys `panel.try.example.*.text`), identical in `en`/`es` since they are CO input data, not interface text.

**What would invalidate it.** The video needing a screenshot example from the panel (needs multipart), or wanting the real Spark behind the token (costs money and latency; Angel's call).

**Addendum (2026-10-31).** The POST reloads the whole page and the result sits below the table, out of view, with no JS to signal anything new arrived. Options: (a) nothing, the shopkeeper scrolls and compares; (b) an `#resultado` anchor on the form's `action` + `id="resultado"` on the block, so the browser jumps there on reload, plus a "Result · HH:MM" heading and a pure-CSS entry animation respecting `prefers-reduced-motion: reduce`. Decision: (b), still no JS, CSP unchanged. The `#resultado` fragment never reaches the server, so it never touches the `SameSite=Lax` cookie or the CSP.

**What would invalidate it.** The panel growing enough that the result needs its own page.
