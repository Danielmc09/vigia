# ADR-031 · Lookalike domains: <=2 edits on labels of >=6 letters, homoglyphs always; brand matched as a whole token (2026-10-27, Claude Code; revised same day)

**Context.** specs/04 asks for "domain similar to an official one" as a hard signal; unrestricted edit distance makes `apps.com` ~ `apple.com` or `ups.com` ~ anything 3 letters long trigger false positives that hurt `fp_legitimo`.
**Options.** Levenshtein <=2 with nothing else; <=1; <=2 only if the official label has >=6 characters, plus a confusable skeleton (0->o, 1->l, rn->m, vv->w, Cyrillic, punycode) at distance 0.
**Decision.** The third (`LOOKALIKE_MAX_EDITS = 2`, `LOOKALIKE_MIN_LABEL = 6`); also "brand off its domain" only counts if the brand alias is a whole host token (separated by `.`/`-`), a hyphen-free label, or a path token, never a substring. Levenshtein hand-written (no library installed).
**Why.** With short labels two edits turns almost any name into another; with substring matching "ups" shows up inside "groups".

**Revision (ciego-01, incident c-0187):** blind-eval ambiguity #5 was a real bug, not a silent spec gap. `_lookalike` compared only the full registrable-domain skeleton; a homoglyph under a DIFFERENT suffix (`bancolornbia.com.co` mimicking `bancolombia.com`) never matched because the differing suffix already added edits, and the case only became a scam via the analyst. **Decision:** in addition to the full skeleton, also compare the name without the suffix on each side (`domain_name`, the first label) and take the minimum of the two distances; the threshold and the 6-letter floor still apply to the official name without its suffix. Expected side effect, not a bug: foreign subsidiaries of the same brand (`davivienda.com.pa`, `claro.com.ar`, `nequi.me`...) now also trigger `lookalike_domain` alongside `brand_off_domain`; the verdict doesn't change because the latter already condemned it.
**What would invalidate it.** A real lookalike of a short brand (e.g. `upps.com`) the set doesn't catch → incident + a per-brand threshold; or a legitimate 6+ letter domain 1-2 edits from the official name under a different suffix → adjust `LOOKALIKE_MIN_LABEL` or list-exclude it.
