# ADR-079 · Audio: PyAV to convert WhatsApp ogg/opus to WAV (2026-10-28, Claude Code)

**Context.** T-10. WhatsApp delivers voice notes as `audio/ogg; codecs=opus`, and T-11 only accepts WAV mono 16-bit 16kHz (D-070); there's no ffmpeg on the machine or the image.

**Options.** (a) `ffmpeg` via subprocess (needs a system binary everywhere); (b) `opuslib`/`pyogg` (needs system libopus); (c) PyAV (`av`), wheels with ffmpeg bundled in.

**Decision.** (c), `av==19.0.2`; decodes the first audio stream and resamples with `AudioResampler(format="s16", layout="mono", rate=16000)` before `check_wav`. The conversion lives in the adapter `channel/wazenda.py:ogg_to_wav` (the format is WhatsApp's), not in `domain/attachment.py`: specs/09 §1 keeps the domain to pure types and checks, no codecs (reviewer T-10).

**Why.** Zero system dependencies, one call, verified opus→16kHz PCM round trip.

**What would invalidate it.** The wheel not existing for Railway's platform, or a real WhatsApp voice note failing to decode.
