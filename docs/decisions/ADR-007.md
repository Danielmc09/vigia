# ADR-007 · Shared types live in `domain`, one `Rejection` class (2026-10-27, Angel)

**Context.** In Angel's previous technical test, reuse and the requested architecture were missing.
**Options.** Each adapter with its own dicts; a single domain.
**Decision.** `Case`, `Signal`, `Verdict`, `Attachment`, `Rejection` in `domain`; import-linter contracts and duplicate detection in `make check`.
**Why.** A rule that isn't checked doesn't hold under deadline pressure.
**What would invalidate it.** Nothing.
