# ADR-070 · Muse Voice transcribes in code before signals, canonical WAV only (2026-10-27, Claude Code)

**Context.** T-11 needs `transcribe`; specs/03 listed it as an analyst tool with ffmpeg ogg→wav; there's no ffmpeg on the machine (T-02), and without text, deterministic signals (rule 5) see nothing in an audio.

**Options.** (a) a Spark tool `transcribe(attachment_id)`; (b) a code step before signals; (c) send the audio to Spark chat (accepts audio, T-02) with no transcription.

**Decision.** (b). `domain/voice.py` (`Transcript`, port `Transcriber = Callable[[bytes, str], Transcript | Rejection]`), `check_wav` in `domain/attachment.py` next to `check_image`, adapter `model/voice.py:VoiceClient` (`POST {base}/asr/transcribe?sessionId=<uuid4>`, multipart `request` = `{"model":"muse-voice-transcribe-1.0","audioEncoding":"WAV","languageBias":[<pack language>]}` + `audio`; returns `transcript`; cost `audioDurationMs/3,600,000 × $0.18`; any HTTP or shape failure → retryable `MODEL_UNAVAILABLE`), `services/transcription.py` (checks before spending; `reply` maps a rejection to i18n key `audio.*`). The text goes to `Case.text`, `kind` stays `audio`; in evals the `Transcript` travels explicitly (`measure._hear` → `to_case(heard=...)`) and its cost is added to the case USD; without a country pack audio is not transcribed (never guess `es`). Caps: reuses `MAX_ATTACHMENT_BYTES` (10 MB) and adds `Settings.voice_max_seconds` (`VIGIA_VOICE_MAX_SECONDS`, 120 s). Format: WAV mono 16-bit 16kHz only; anything else (including WhatsApp's ogg/opus) is a typed rejection `UNSUPPORTED_AUDIO`/`AUDIO_TOO_LONG`, never an exception; ffmpeg comes with T-10/T-19. Evals: 10 synthetic audios via macOS `say` (c-0145..c-0154); Angel will replace/extend with real recordings. `tools/measure.py`: in `--solo-deterministas`, audios without `texto` are always SKIPPED; in full mode too if there's no `MODEL_API_KEY` — counting them as failures would lower `recall_estafa` against a baseline that never could transcribe.

**Why.** Hard signals need the words before the analyst decides whether it's needed; a tool-based approach would leave audio cases decided with no text; option (c) is unreviewed model text and costs more.

**What would invalidate it.** Voice not transcribing real Colombian Spanish recordings well (accuracy for `tipo=audio` < 0.80), or native audio to Spark beating transcription+signals at the same cost.
